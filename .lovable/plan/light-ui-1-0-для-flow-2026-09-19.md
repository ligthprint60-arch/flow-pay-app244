# Light UI 1.0 для FLOW

## Цель
Перестроить визуальный язык приложения вокруг причинно-следственного света: источник → распространение → реакция → затухание. Сохранить читаемость, существующую функциональность и производительность ChronosGPU.

## Что изменится

### 1. Единое световое поле
- Добавить глобальный Light System поверх существующего GPU-фона: курсор и касание создают локальный источник, а нажатия — короткий импульс.
- Свет будет иметь координаты, радиус, интенсивность, цвет состояния и плавное затухание.
- События успеха, предупреждения и ошибки получат разные, но сдержанные импульсы; свет не станет единственным обозначением состояния.

### 2. Системный визуальный язык
- Заменить постоянное декоративное свечение на спокойный почти тёмный ambient-слой.
- Оставить собственный свет только интерактивным и активным элементам.
- Переработать стеклянные поверхности: они отражают ближайший источник, создают направленный блик и окклюзионную тень, но не светятся постоянно.
- Ввести токены интенсивности, радиуса, длительности, температуры, falloff и глубины для всех эффектов.

### 3. Интерактивные компоненты
- Кнопки: локальный источник при наведении/фокусе, импульс от точки нажатия, затухание после действия.
- Поля ввода: направленный свет фокуса и короткий фотонный импульс при наборе; состояние ошибки остаётся текстовым и цветовым.
- Карточки и окна: реакция на положение источника, отражение и корректная тень между слоями.
- Нижняя навигация: активный раздел становится движущимся источником, который переносится между пунктами без постоянного glow.
- Уведомления: входящий световой импульс с последующей стабилизацией.

### 4. Доступность и уровни качества
- Добавить настройку «Reduced Light» и связать её с системным reduced-motion.
- Пресеты графики будут управлять уровнями Static / Dynamic / Photonic.
- В экономном режиме останутся статические фокус и состояния; в балансе — ограниченное динамическое поле; в ультра — полный интерактивный свет.
- Исключить вспышки, бесконечные пульсации и световой шум; сохранить контраст текста и видимые focus-состояния.

### 5. Проверка
- Проверить вход, кошелёк, нижнюю навигацию, окна настроек, уведомления и поля ввода на мобильном и десктопном размерах.
- Проверить все четыре графических пресета и RU/EN.
- Убедиться, что при выключении эффектов интерфейс остаётся полностью понятным и функциональным.

## Технические детали
- Новый глобальный слой будет работать через один делегированный обработчик событий и CSS-переменные, без отдельных анимационных объектов для каждого элемента.
- Существующий ChronosGPU останется рендерером пространственной реакции; DOM отвечает только за семантические состояния и доступность.
- Основные изменения затронут глобальные токены/стили, оболочку приложения, базовые Button/Input, настройки графики и уведомления; страницы унаследуют систему через существующие классы поверхностей.
